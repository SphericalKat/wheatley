In a few minutes, you will have Wheatley running locally with both a terminal chat and a web dashboard.

<Steps>

1. **Initialize your Wheatley folder**

   Run `wheatley init`. By default, this creates `~/.wheatley` (or `$WHEATLEY_HOME` if set) with `config.yaml`, `secrets.yaml`, and a workspace for your first assistant (`default`). It never overwrites an existing `config.yaml`.

   ```bash
   wheatley init
   ```

   <Aside type="tip" title="Using another provider or folder">
     Pass `--provider`, `--model`, `--agent`, or `--home` to customize the initial setup, for example `wheatley init --provider openai --model gpt-5.4-mini`.
   </Aside>

2. **Add your API key**

   Open `~/.wheatley/secrets.yaml` and add the key for your provider (for the default Anthropic setup):

   ```yaml
   ANTHROPIC_API_KEY: sk-ant-...
   ```

   See [Configuration](/wheatley/reference/configuration/) for environment variable overrides and secret handling.

3. **Start chatting**

   Open the interactive terminal chat:

   ```bash
   wheatley
   ```

   Or send a one-off question from your shell:

   ```bash
   wheatley ask "What can you help me with?"
   ```

   If no daemon is running, `wheatley` (or `wheatley chat`) and `wheatley ask` start a temporary in-process daemon for that session and stop it when you exit.

4. **Run the persistent daemon (optional)**

   To keep Wheatley running for the web dashboard, scheduled triggers, and chat apps (Telegram, Slack, Discord), start the daemon in your terminal:

   ```bash
   wheatley daemon
   ```

   <Aside type="note">
     If you start the daemon before adding an API key, Wheatley still runs, but marks your assistant as `degraded` until the key is added.
   </Aside>

5. **Check status and open the web dashboard**

   While the daemon runs, check assistant health in another terminal with `wheatley status`, or open `http://127.0.0.1:7420/` in your browser to chat, approve tool calls, view memory, and edit settings visually.

   ```bash
   wheatley status
   ```

</Steps>
