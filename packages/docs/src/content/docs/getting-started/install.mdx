## Before you begin

- **An AI provider API key** (for example, from Anthropic, OpenAI, or Google).
- **Node.js `26.13.1` or newer** if you install with npm, pnpm, yarn, or bun. The install script downloads a matching Node.js runtime automatically if needed.
- **Docker** if you prefer running Wheatley in a container.

## Choose an install method

<Tabs syncKey="install-method">
  <TabItem label="Install script">
    Recommended for macOS (`arm64`, `x64`) and standard glibc Linux (`x64`, `arm64`):

    ```bash
    curl -fsSL https://raw.githubusercontent.com/SphericalKat/wheatley/main/scripts/install.sh \
      | sh
    ```

    To pin a specific version or skip automatic edits to your shell profile, pass flags after `--`:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/SphericalKat/wheatley/main/scripts/install.sh \
      | sh -s -- --version 0.3.0 --no-modify-path
    ```

    Open a new terminal window (or run the `export PATH=...` line printed by the script) so your shell can find `wheatley`.

    ### Where files are installed

    The script puts program files in standard XDG folders and leaves `~/.wheatley` free for your personal data and config:

    | Location | Contents |
    | --- | --- |
    | `${XDG_DATA_HOME:-$HOME/.local/share}/wheatley/app` | Wheatley CLI package |
    | `${XDG_DATA_HOME:-$HOME/.local/share}/wheatley/runtime` | Managed Node.js `26.13.1` (downloaded only when needed) |
    | `${XDG_BIN_HOME:-$HOME/.local/bin}` | `wheatley` executable |

    <Aside type="note" title="Linux notes">
      - If your machine already has Node.js `26.13.1+` and `npm`, the script reuses them. Otherwise it downloads Node.js from `https://nodejs.org/dist`, verifies its SHA-256 checksum, and supports a custom mirror via `WHEATLEY_NODE_MIRROR`.
      - On Debian or Ubuntu, the managed Node.js binary requires `libatomic1`.
      - On musl systems such as Alpine Linux, install Node.js `26.13.1+` from your system package manager first, or use the Docker image instead.
    </Aside>
  </TabItem>

  <TabItem label="npm / pnpm">
    Requires Node.js `26.13.1` or newer on your machine:

    <Tabs syncKey="pkg-manager">
      <TabItem label="npm">
        ```bash
        npm install --global @wheatley-ai/cli
        ```
      </TabItem>
      <TabItem label="pnpm">
        ```bash
        pnpm add --global @wheatley-ai/cli
        ```
      </TabItem>
      <TabItem label="yarn">
        ```bash
        yarn global add @wheatley-ai/cli
        ```
      </TabItem>
      <TabItem label="bun">
        ```bash
        bun install --global @wheatley-ai/cli
        ```
      </TabItem>
    </Tabs>

    Append `@<version>` (for example, `@wheatley-ai/cli@0.3.0`) to install a specific release.
  </TabItem>

  <TabItem label="Homebrew">
    Install from the official tap on macOS or Linux:

    ```bash
    brew install sphericalkat/tap/wheatley
    ```

    Homebrew installs its `node` formula automatically if it is not already present.
  </TabItem>

  <TabItem label="AUR">
    Install `wheatley-cli` with your AUR helper:

    ```bash
    paru -S wheatley-cli
    # or
    yay -S wheatley-cli
    ```

    This package uses Arch's `nodejs` package and links `/usr/bin/wheatley`.
  </TabItem>

  <TabItem label="Docker">
    The container image (`ghcr.io/sphericalkat/wheatley`) stores Wheatley data in `/data` and runs `wheatley daemon` automatically.

    | Image tag | What you get |
    | --- | --- |
    | `<major>.<minor>.<patch>` | One exact release (for example `0.3.0`) |
    | `<major>.<minor>` | Newest patch in that minor series |
    | `<major>` | Newest release in that major series |
    | `latest` | Newest release |

    <Aside type="caution">
      While Wheatley is on `0.x`, minor releases can introduce breaking changes. Pin a `<major>.<minor>` or exact version tag if you want predictable upgrades.
    </Aside>

    <Tabs>
      <TabItem label="Docker Compose">
        The Compose file in `docker/docker-compose.yml` uses `WHEATLEY_TAG` (default `0`) and binds port `7420` to `127.0.0.1` so the dashboard stays local.

        <Steps>

        1. Move into the `docker` folder and pull the image:

           ```bash
           cd docker
           docker compose pull
           ```

        2. Initialize `config.yaml` and `secrets.yaml` inside `/data`:

           ```bash
           docker compose run --rm wheatley wheatley init
           ```

        3. Allow the dashboard to accept connections through Docker's port mapping:

           ```bash
           docker compose run --rm wheatley sh -c 'printf "daemon:\n  host: 0.0.0.0\n  port: 7420\n" >> /data/config.yaml'
           ```

        4. Save your API key in `secrets.yaml`:

           ```bash
           docker compose run --rm wheatley sh -c 'echo "ANTHROPIC_API_KEY: <your key>" >> /data/secrets.yaml'
           ```

        5. Start Wheatley and open the dashboard at `http://127.0.0.1:7420/`:

           ```bash
           docker compose up -d
           ```

        </Steps>
      </TabItem>

      <TabItem label="docker run">
        <Steps>

        1. Create a Docker volume for your Wheatley data:

           ```bash
           docker volume create wheatley-data
           ```

        2. Initialize `config.yaml` and `secrets.yaml`:

           ```bash
           docker run --rm -v wheatley-data:/data ghcr.io/sphericalkat/wheatley:latest wheatley init
           ```

        3. Allow the dashboard to listen on all container interfaces:

           ```bash
           docker run --rm -v wheatley-data:/data ghcr.io/sphericalkat/wheatley:latest sh -c 'printf "daemon:\n  host: 0.0.0.0\n  port: 7420\n" >> /data/config.yaml'
           ```

        4. Save your API key in `secrets.yaml`:

           ```bash
           docker run --rm -v wheatley-data:/data ghcr.io/sphericalkat/wheatley:latest sh -c 'echo "ANTHROPIC_API_KEY: <your key>" >> /data/secrets.yaml'
           ```

        5. Start the container and open the dashboard at `http://127.0.0.1:7420/`:

           ```bash
           docker run -d --name wheatley --init --restart unless-stopped --stop-timeout 45 \
             -p 127.0.0.1:7420:7420 -v wheatley-data:/data ghcr.io/sphericalkat/wheatley:latest
           ```

        </Steps>
      </TabItem>
    </Tabs>
  </TabItem>

  <TabItem label="Source">
    Requires Node.js `26.13.1+` and `pnpm` `12.23.0`.

    <Steps>

    1. Clone the repository and enter the folder:

       ```bash
       git clone https://github.com/SphericalKat/wheatley.git
       cd wheatley
       ```

    2. Install dependencies and build all packages:

       ```bash
       pnpm install
       pnpm build
       ```

    3. Test the CLI:

       ```bash
       node packages/wheatley/bin/wheatley.js --help
       ```

    </Steps>

    When running from a source checkout, replace `wheatley` with `node packages/wheatley/bin/wheatley.js` in the commands throughout these docs.
  </TabItem>
</Tabs>

## Verify your installation

```bash
wheatley --version
```

Once it prints a version number, head to the [Quick start](/wheatley/getting-started/quick-start/).
