## Run Wheatley as a background service

`wheatley service` sets up a user-level background service using `systemd --user` on Linux and `launchd` on macOS, so Wheatley starts automatically when you log in:

```bash
wheatley service install
wheatley service start
wheatley service status
```

To stop or restart the service (for example, after upgrading or editing `config.yaml`):

```bash
wheatley service restart
wheatley service stop
```

## Check for updates and upgrade

Check whether a newer version is available without changing anything:

```bash
wheatley update --check
```

Install the newest release in your current major version:

```bash
wheatley update
```

`wheatley update` detects how you originally installed Wheatley and runs the right upgrade command for you. You can override auto-detection with `--method` (`npm`, `pnpm`, `yarn`, `bun`, `brew`, or `curl`).

| Install method | What `wheatley update` does |
| --- | --- |
| Install script (`curl`) | Re-runs `install.sh` pinned to the new version |
| `npm`, `pnpm`, `yarn`, `bun` | Installs `@wheatley-ai/cli@<version>` globally and verifies the updated version |
| Homebrew | Runs `brew upgrade sphericalkat/tap/wheatley` |
| Volta / mise / AUR / Docker | Prints the native upgrade command for you to run |
| Source checkout | Stops and reminds you to update via `git` (or pass `--method`) |

:::note Major version upgrades (for example `0.x` to `1.0`) are never installed automatically — Wheatley prints the upgrade command so you can review breaking changes first. After upgrading, restart the daemon (`wheatley service restart`). :::

## Restore an assistant backup

Wheatley automatically backs up each assistant's SQLite database (`agents/<name>/agent.sqlite`) before every database migration and before every restore, keeping the five newest backups in `agents/<name>/backups/`.

<Steps>
  1. **List available backups**

     ```bash
     wheatley restore default
     ```

2.  **Stop the daemon**

    `wheatley restore` refuses to run while Wheatley is active:

    ```bash
    wheatley service stop
    ```

3.  **Restore the backup you want**

    ```bash
    wheatley restore default <backup-file>
    ```

4.  **Start the daemon again**

         ```bash
         wheatley service start
         ```

    </Steps>
