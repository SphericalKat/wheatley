You can talk to your Wheatley assistants from the command line or from your browser — both stay in sync with the same conversations and approvals.

## Quick one-shot questions (`wheatley ask`)

Send a single prompt and print the reply:

```bash
wheatley ask "Summarize today's notes"
```

You can also pipe input into `wheatley ask`:

```bash
git diff | wheatley ask "Explain these changes in three bullet points"
```

<Aside type="note">
  When input is piped (not an interactive terminal), `wheatley ask` automatically denies any tool call that requires manual approval so scripts never hang waiting for a prompt.
</Aside>

## Interactive terminal chat (`wheatley chat`)

Run `wheatley chat` to open the full-screen terminal interface:

- Replies stream live with formatted Markdown and word-wrapped code blocks.
- Tool calls appear inline with their input, result, and duration.
- When a run takes 10 seconds or longer, or pauses for your approval, your terminal receives a notification bell.

If you pipe input into `wheatley chat`, it switches automatically to a plain line-by-line mode.

### Slash commands

Type `/` to open the interactive command menu:

| Command | What it does |
| --- | --- |
| `/new` | Start a fresh conversation |
| `/model <model-id>` | Switch models for the current conversation |
| `/compact` | Summarize and compact the conversation to save context |
| `/stop` | Stop the currently running reply |
| `/goal <objective>` | Start a longer autonomous run toward a goal |
| `/status` | Show active conversation, model, and assistant health |
| `/restart` | Restart this assistant (for example after editing `config.yaml`) |
| `/copy` | Copy the last reply to your clipboard (works over SSH with OSC 52) |
| `/help` | Show commands and keyboard shortcuts |
| `/exit` | Leave the chat |

### Helpful shortcuts

- Start a line with `!` to run a local shell command without sending it to your assistant (for example `!git status`).
- End a line with `\` and press `Enter`, or press `Alt+Enter`, to add a new line.
- Press Up and Down arrows to browse your prompt history (saved in `~/.wheatley/chat_history`).
- Use `Ctrl+W`, `Ctrl+U`, and `Ctrl+K` to delete the previous word, text before the cursor, or text after the cursor.
- Press `Esc` to close the menu or interrupt a running reply. Press `Esc` twice to clear the input line.
- Press `Ctrl+C` to clear the line, stop a run, or exit on a second press. `Ctrl+D` exits on an empty line.

## Approving sensitive actions

When an assistant wants to run a tool whose rule is `ask` (such as `shell` or `write_file`), Wheatley pauses and shows you the exact tool name and arguments. Choose one of four responses:

- **`o` (once)**: Allow this single tool call.
- **`c` (conversation)**: Allow this tool for the rest of the current conversation.
- **`a` (always)**: Allow this tool permanently (adds an `allow` rule to the top of `permissionPolicy` in `config.yaml`).
- **`d <reason>` (deny)**: Deny the call and tell your assistant why (or press `Esc` to deny without a reason).

## Web dashboard

Open `http://127.0.0.1:7420/` in your browser while the daemon is running.

- **Deployment views**: Overview, Inbox (pending approvals), Logs, and Secrets.
- **Per-assistant views**: Chat, Runs, Memory, Triggers and Extensions, and Config.

<Aside type="caution" title="Keep the dashboard local">
  Wheatley's local web dashboard does not have built-in login authentication. Keep `daemon.host` bound to `127.0.0.1` (or access it over an SSH tunnel or private VPN such as Tailscale). Browser connections from other origins are blocked unless you list them in `daemon.allowedOrigins`.
</Aside>
