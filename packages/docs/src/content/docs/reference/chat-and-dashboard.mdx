## One-shot prompts (`wheatley ask`)

`wheatley ask "<prompt>"` sends a single prompt and prints the reply. `ask` also reads from standard input. When standard input is not a terminal, `ask` automatically denies any Tool call that requires an Approval.

## Interactive CLI Chat (`wheatley chat`)

`wheatley chat` opens a full-screen terminal chat for an Agent. The web dashboard displays the same Chat. If your Deployment has more than one Agent and none is named `default`, pass `--agent <name>`.

If standard input or output is not a terminal (for example, a pipe), `wheatley chat` reads and writes plain lines.

### Chat slash commands

| Command | Action |
| --- | --- |
| `/new` | Start a new Conversation in this Chat |
| `/model <model-id>` | Switch to another model for this Conversation |
| `/compact` | Compact the current Conversation |
| `/stop` | Stop the active Run in this Chat |
| `/goal <objective>` | Start a long-running autonomous Run |
| `/status` | Show the Conversation, Run, model, and Agent health |
| `/restart` | Restart this Agent |
| `/copy` | Copy the last reply to the clipboard (supports OSC 52 over SSH) |
| `/help` | List commands and keybindings |
| `/exit` | End the Chat |

### Input shortcuts

- Type `/` to open the command menu. Use Up/Down to select, `Tab` or Right to complete, and `Enter` to run.
- Start a line with `!` to run a local shell command in the current folder (for example `!git status`) without sending it to the Agent.
- End a line with `\` and press `Enter`, or press `Alt+Enter`, to insert a newline.
- Use Up and Down arrows to recall earlier prompts from `<home>/chat_history`.
- Use `Ctrl+W`, `Ctrl+U`, and `Ctrl+K` to delete the previous word, text before the cursor, or text after the cursor.
- Press `Esc` to close the menu or interrupt the active Run. Press `Esc` twice to clear the input line.
- Press `Ctrl+C` to clear the line, then stop the Run, then exit on a second press. Press `Ctrl+D` on an empty line to exit.

## Approvals

When a Tool call requires an Approval, Wheatley shows the Tool name and its input. Respond with one of these actions:

- `o`: allow this call once.
- `c`: allow this Tool for the rest of this Conversation.
- `a`: allow this Tool always (prepends an `allow` rule to `permissionPolicy` in `config.yaml`).
- `d <reason>`: deny this call and send the reason back to the Agent. Press `Esc` to deny without a reason.

## Web dashboard

The daemon serves the web dashboard on its TCP listener, by default `http://127.0.0.1:7420/`.

- **Deployment views**: Overview, Inbox, Logs, Secrets.
- **Per-Agent views**: Chat, Runs, Memory, Triggers and Extensions, Config.

:::caution The Control Server has no authentication. Keep the TCP listener on a loopback address (`127.0.0.1`). The server rejects browser WebSocket connections from foreign origins unless you add them to `daemon.allowedOrigins`. :::
