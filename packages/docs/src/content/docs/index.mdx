## Why run Wheatley

<CardGrid>
  <Card title="Always on, locally owned" icon="laptop">
    Run Wheatley on a laptop, home server, or small VPS. Your config,
    conversations, and memory stay in plain files and SQLite under your home
    folder.
  </Card>
  <Card title="Bring your own models" icon="setting">
    Use Anthropic, OpenAI, Google, OpenRouter, Groq, Mistral, xAI, DeepSeek, or
    any OpenAI-compatible endpoint. Run multiple independent assistants in one
    setup.
  </Card>
  <Card title="Chat from anywhere" icon="comment">
    Message your assistant in the terminal, in the built-in web dashboard, or
    through Telegram, Slack, and Discord. Approve or deny sensitive actions
    directly in chat.
  </Card>
  <Card title="Built to grow with you" icon="puzzle">
    Add tools with MCP servers, drop in Markdown skills, schedule recurring
    reminders or webhooks, and write custom TypeScript plugins when you need
    more.
  </Card>
</CardGrid>
