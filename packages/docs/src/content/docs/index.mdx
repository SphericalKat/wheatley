## Core capabilities

<CardGrid>
  <Card title="Install in minutes" icon="download">
    Install on macOS or Linux with the install script, npm, pnpm, Homebrew, AUR,
    or Docker. Run the daemon in the foreground or as a background service.
  </Card>
  <Card title="Any supported model or agent setup" icon="setting">
    Connect Agents to Anthropic, OpenAI, Google, OpenRouter, Groq, Mistral, xAI,
    DeepSeek, or an OpenAI-compatible proxy. Run multiple isolated Agents in one
    Deployment.
  </Card>
  <Card title="Chat anywhere" icon="comment">
    Talk to an Agent from the CLI, the built-in web dashboard, Telegram, Slack,
    or Discord. Approve or deny sensitive Tool calls directly in chat.
  </Card>
  <Card title="Extend with MCP, skills, and plugins" icon="puzzle">
    Attach stdio or HTTP MCP Servers, load Markdown Skills on demand, schedule
    cron or webhook Triggers, and write TypeScript Plugins with
    `@wheatley-ai/sdk`.
  </Card>
</CardGrid>
