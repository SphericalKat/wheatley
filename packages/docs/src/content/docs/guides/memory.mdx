---
title: Memory
description: How Wheatley remembers preferences and facts across conversations, and how to inspect or tune it.
---

Each assistant keeps long-term memory in plain Markdown files under `~/.wheatley/agents/<name>/memory/`.

The main file is `MEMORY.md`. Whenever you start a new conversation, your assistant reads `MEMORY.md` automatically so you do not have to repeat preferences, ongoing projects, or context. During a conversation, your assistant can search, read, update, or remove memory entries on its own.

## Inspect or edit memory

You can view or edit an assistant's memory in the **Memory** tab of the [web dashboard](/wheatley/reference/chat-and-dashboard/#web-dashboard), or open `~/.wheatley/agents/<name>/memory/MEMORY.md` directly in any text editor.

## Tune memory size and daily cleanup

By default, `MEMORY.md` is capped at `4,000` characters, and Wheatley runs a daily cleanup job at `03:00` to keep memory concise and remove stale notes.

Customize these settings under `agents.<name>.memory` in `config.yaml` (set `enabled: false` to disable automatic cleanup and manage `MEMORY.md` yourself):

```yaml
agents:
  default:
    memory:
      maxChars: 8000
      consolidation:
        enabled: true
        schedule: "0 3 * * *"
        timezone: "America/New_York"
        model:
          provider: anthropic
          id: claude-sonnet-5-5
```
